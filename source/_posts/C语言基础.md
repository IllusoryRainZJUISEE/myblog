### 整数的两种类型
```c
1. 整数的两种类型
(1) 符号数(signed number): 包括正整数、负整数、零
计算机中用补码(two`s complement)表示一个符号数
8位正整数的二进制补码的最高位恒为0，其余各位表示该数的值，例如: +127 = 0111 1111
如何用8位二进制补码表示-1？
+1 = 0000 0001           +2 = 0000 0010
-1 = 1111 1111 +)        -2 = 1111 1110
------------------
     0000 0000

+127 = 0111 1111        -128 = 1000 0000
-127 = 1000 0001        +127 = 0111 1111
                        +1   = 0000 0001 +)
                        -------------------
                                       0

8位正整数的取值范围是[0000 0000, 0111 1111]即[0x00,0x7F]或[0, 127]
8位负整数的取值范围是[1000 0000, 1111 1111]即[0x80,0xFF]或[-128, -1]

① 8位符号数即char类型的取值范围是[1000 0000, 0111 1111]
即[0x80, 0x7F]或[-128, +127]
char的输入/输出格式: %c、%hhd、%hhx、%hho
用getchar()这个函数可以对char或unsigned char类型的变量做输入
用putchar()则可以用符号的形式输出某个char或unsigned char

② 16位符号数short int的取值范围[1后面15个0, 0后面15个1]即
[0x8000, 0x7FFF]或[-32768, +32767], 输入/输出格式: 
%hd、%hx、%hX、%ho

③ 32位符号数long int的取值范围[1后面31个0, 0后面31个1]即
[0x80000000, 0x7FFFFFFF]或[-2147483648, +2147483647], 
输入/输出格式: %ld、%lx、%lX、%lo

④ int是对short int、long int的抽象, 它在Dev-C++中等价于
long int，在TC中等价于short int，输入/输出格式: 
%d、%x、%X、%o


-1 的8位二进制补码  =1111 1111
-1 的16位二进制补码 =16个1
-1 的32位二进制补码 =32个1

(2) 非符号数(unsigned number): 仅包含零及正整数
① unsigned char 是8位的非符号整数类型
取值范围是[0000 0000, 1111 1111], 即[0x00, 0xFF]或
[0, 255], 输入/输出格式: %c、%hhu、%hhx、%hhX、%hho
其中u表示十进制非符号整数格式, 输出结果一定是非零值

③ unsigned long int 是32位的非符号整数类型
取值范围是[32个0, 32个1], 即[0x00000000, 0xFFFFFFFF]或

其中o表示八进制(octal)
④ unsigned int 是对unsigned short int及unsigned long int的抽象,
它在某些编译器中如dev-C++中等价于unsigned long int，而在另外

%u、%x、%o
```

```d
3. 截断与扩充
(1) 整数的截断: 当把宽度大的值赋值给宽度小的变量时会发生截断，截断的

short int a=0x1234; // 0x1234=0001 0010  0011 0100

(2) 小数的截断: 当把小数赋值给整型变量时会发生截断, 截断时
仅保留整数部分，丢弃小数部分;
float a=3.95;
int b, c;

c = a + 0.5; // c=4 四舍五入

b = a;        //             ~~~~~~~~~

(4) 当对负整数右移时须在左边补1，对正整数右移时则在左边补0
```
