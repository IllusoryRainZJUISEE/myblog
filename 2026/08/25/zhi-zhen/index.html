指针

1. 指针(pointer)        
指针就是地址(address)   
计算机的内存(memory)中，每个字节均可以分配到一个地址
一个内存变量一定同时具备2个属性:(1)地址 (2)值
值可以改变，地址不可更改
变量的地址不占内存空间，变量的值会占用内存空间
①x的地址=1000 ②1000是x的指针 ③1000指向(point to)x
 地址  值(value)          当某个变量跨越多个地址时，其整体的
+1000 0x78}x \            的地址是最小的那一个，故&y=1000
+1001 0x56   /y           char *p; 定义一个指针变量p，它指向一个char
+1002 0x34                p=&x;    
+1003 0x12           short int *q; 定义一个指针变量q，它指向一个short int
                          q=&y;    
short int *是q的类型，short int是q指向的对象的类型
当p被赋值为某个char类型变量的地址时，称p指向那个char

7. 指针相关的3个概念: 野指针、空指针、通用指针
(1)野指针
char a='A', b, *p;
*p = a; // 此处的p就是野指针(wild pointer)
b = *p;
正确的写法应该是:
p = &a; // 引用*p前先对p本身赋值可以防止野指针
b = *p
或
p = &b;
*p = a;

putchar(b);

(2) 空指针(NULL pointer)
当指针变量p=0时，称p是空指针，故0地址就是空指针
C语言规定，0地址对应内存单元中不能存放任何对象(变量、数组、函数)
#include <stdio.h>
int *f(int a[], int n, int x)
{
   int i;
   for(i=0; i<n; i++)
   {
      if(a[i] == x)
         return &a[i];
   }
   return NULL; // 或 return 0;
}

main()
{
   int x[5]={11,22,33,44,55}, d=66, *p;
   p = f(x, 5, d);
   if(p != NULL)
      printf("%d is found at %p", d, p);
   else
      printf("%d is NOT found", d);
}

8. 指针作为函数的参数
(1) 参数的传递方法之一: 值传递(call by value)
void f(int p) // 形参p与实参a不是同一个变量
{             // 即使把形参名改成a, 实参与形参仍旧不是同一变量
   printf("&p=%p\n", &p);
   p = -p;
}
main()
{
   int a=123;
   printf("&a=%p\n", &a);
   f(a); // 实参a代表的a的值
   printf("a=%d", a); // a=123
}

(2) 参数的传递方法之一: 地址传递(call by reference)
void f(int *p) // p = &a
{
   *p = -*p;   // a = -a
}
main()
{
   int a=123;
   f(&a); // 实参是地址
   printf("a=%d\n", a); // a=-123
}

void swap(int *p, int *q)
{
   int t;
   t = *p;
   *p = *q;
   *q = t;
}
main()
{
   int a=123, b=456;
   swap(&a, &b);
   printf("a=%d, b=%d\n", a, b); // a=456, b=123
}

int f(int x, int y, int *p)
{
   *p = x - y;
   return x+y;
}
main()
{
   int a=5, b=3, c, d;
   c = f(a, b, &d);
   printf("c=%d, d=%d\n", c, d); // c=8, d=2
}

9. 指针和一维数组的关系
(1) 设a是一个一维数组，则一定有a[i]≡*(a+i)，因为一维数组
    名a可以理解为该数组的首元素的地址，即a≡&a[0]
    char a[4] = "ABC", c;
    c = a[1];   // c = 'B'
    c = *(a+1); // c = 'B'
(2) 设p是一个指针变量，则一定有p[i]≡*(p+i);
    p[0]可看作是p指向的第0个元素即p当前指向的对象,
    p[i]可看作是p指向的第i个元素   
    char a[4] = "ABC", c, d, *p;
    p = &a[1];
    c = p[-1]; // c = 'A'
    c = *(p-1);// c = 'A'
    d = p[1];  // d = 'C'
    d = *(p+1);// d = 'C'
(3) 数组名a与指针变量p的异同
①共性
a[i]≡*(a+i)
p[i]≡*(p+i)
*(a+i)≡a[i]
*(p+i)≡p[i]
②差别
(a) p可以被赋值但a不能被赋值
(b) sizeof(a) ≠ sizeof(p); 
例如: char a[10] = "ABC", *p; // 10 ≠ 4, 
sizeof(a)中的a必须理解为数组a, 不能理解成&a[0]
(c) &a ≠ &p
&a中的a必须理解成数组a，不能理解成&a[0]

(4) 一维数组做函数实参的本质是以首元素的地址做参数
void f(char s[]) //编译器会把char s[]转换成char *s
{//等价于char *s //s=&a[0]
   int i=0;
   while(s[i] != '\0') // s[i]等价于 *(s+i)
   {
      if(s[i] >= 'a' && s[i] <= 'z')
         s[i] -= 'a' - 'A';
      i++;
   }
}
main()
{
   char a[10] = "AxByCz";
   f(a); // 等价于 f(&a[0]);
   puts(a); // AXBYCZ
}

1. 指针与二维数组的关系
(1) 二维数组名可以理解成该数组首行的地址，即a≡&a[0];
    若q=a;或q=&a[0], 那么q的类型必须是数组指针
short a[3][4] = 
{// 设&a[0][0]=1000, 则&a[0][1]=1002, &a[0][2]=1004, 
 // &a[0][3]=1006, &a[1][0]=1008, &a[2][0]=1016
 // &a[0]=1000, &a[1]=1008, &a[2]=1016
   {0,  1, 2, 3},
   {10,11,12,13},    // q[0]≡*q≡a[1]
   {20,21,22,23}     // q[1]≡*(q+1)≡a[2]
};
short *p;
short (*q)[4]; // q是数组指针，它指向一个由4个short构成的
               // 一维数组。q is pointer to an array 
               // of 4 short integers.
q = &a[0];     // q=&a[0];也可以写成q=a;
               // &a[0]表示a[0]行的地址, 这里的a[0]不能理解成&a[0][0]           
q++; 
printf("%hd", **q);         // **q=*a[1]=a[1][0]=10
printf("%hd", q[1][1]);     // a[2][1]=21
printf("%hd", (*(q+1))[3]); // a[2][3]=23
printf("%hd", *(q[1]+2));   // 22
printf("%hd", *(*(q+1)+1)); // 21

p = &a[0][0];  // 或写成p=a[0]; 这里的a[0] ≡ &a[0][0]
p++;
printf("%hd", *p); // 1

2. main()的参数
设源程序名为m.c，那么m.c编译后会生成m.exe
不带参数的m.exe的运行方法有以下3种:
(1) 在dev-c++中点菜单"运行->运行"
(2) 鼠标双击m.exe
(3) 把m.exe拷到d:\, 再做以下步骤:
    ①右键点Windows桌面左下角的开始->运行->输入cmd->确定
    ②d:
    ③cd \
    ④m
带参数的m.exe的运行方法有以下2种:
(1) 把m.c拖到dev-c++中打开，再做以下步骤:
    ①点菜单"运行->编译"
    ②点菜单"运行->参数"->勾选"使用下列参数运行程序"->传递给主程序的参数设为"100 200 300"
    ③点菜单"运行->运行"
(2) 把m.exe拷到d:\, 再做以下步骤:
    ①右键点Windows桌面左下角的开始->运行->输入cmd->确定
    ②d:
    ③cd \
    ④m 100 200 300 
上述第④步输入的内容"m 100 200 300"称为m.exe的4个参数(实际上是4个字符串)，其中
   参数0="m"
   参数1="100"
   参数2="200"
   参数3="300"
操作系统会在运行m.exe前把这4个字符串的首元素的地址分别保存到
指针数组char *a[4]的各个元素中:
   a[0] = "m";    // 即a[0]=&"m"[0];
   a[1] = "100";  // 即a[1]=&"100"[0];
   a[2] = "200";  // 即a[2]=&"200"[0];
   a[3] = "300";  // 即a[3]=&"300"[0];
接着，操作系统会统计数组a中的元素个数即4代入以下main()函数的形参n中，
再把&a[0]即a代入以下main()函数的形参v中:
           //或 char *v[]
int main(int n, char **v)
{
   int i;
   for(i=0; i<n; i++)
      puts(v[i]); // 或puts(*(v+i));
}
按照带参数的m.exe的运行方法运行以上程序会输出以下4个字符串:
m↲
100↲
200↲
300↲
其中形参v与a[i]的关系如下所示:
          "m"  "100"  "200"  "300"
           ↑    ↑      ↑      ↑
v→ a[0] ---+    |      |      |
   a[1] --------+      |      |
   a[2] ---------------+      |
   a[3] ----------------------+

以下例子的功能是把参数1起的各个参数转化成整数并求和:
#include <stdio.h>
int main(int n, char **v)
{
   int i, sum=0;
   for(i=1; i<n; i++)
      sum += atoi(v[i]); // atoi可以把字符串转化成数值
                         // 如atoi("100")的函数值为100
   printf("sum=%d\n", sum);   
}
